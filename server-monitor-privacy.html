개인정보처리방침

최종 수정: 2026-03-03

"Server Monitor는 사용자의 프라이버시를 최우선으로 하며, 어떠한 데이터도 외부 서버로 전송하지 않는 로컬 기반 모니터링 솔루션입니다."

개요

Server Monitor(이하 "앱")는 사용자가 등록한 서버 및 API의 상태를 모니터링하는 iOS 애플리케이션입니다. 본 앱은 사용자의 개인정보를 수집하거나 외부 서버로 전송하지 않습니다. 모든 데이터는 사용자의 기기 내부에만 저장됩니다.

수집하는 정보

앱은 다음 정보를 사용자의 기기 내부 저장소에만 저장하며, 이는 서비스 제공을 위한 필수 데이터입니다.

  • 사용자가 직접 입력한 서버 이름, URL, HTTP 메서드
  • 인증 정보 (Bearer Token, API Key 등) — 암호화되어 기기 내부에 보관됩니다
  • 체크 주기, 성공 조건 등 앱 설정값
  • 마지막 서버 체크 결과 (상태 코드, 응답 시간 등)

앱은 광고 식별자(IDFA), 위치 정보, 연락처 등 민감한 개인정보를 수집하지 않습니다.

네트워크 요청

  • 서버 상태 체크: 사용자가 등록한 URL에만 HTTP 요청을 보냅니다. 결과는 기기 내부에만 저장됩니다.
  • 공인 IP 조회: IP 제한 기능 사용 시 api.ipify.org에 현재 공인 IP를 조회하며, 조회용 주소 외 어떤 데이터도 전송하지 않습니다.

푸시 알림

서버 이상 감지 시 Push 알림을 발송합니다. Apple 알림 서비스(APNs)를 통해 전달되며, 알림 내용(서버명, 상태)만 포함됩니다. 알림 권한은 기기 설정에서 언제든지 관리할 수 있습니다.

Privacy Policy

Last Updated: 2026-03-03

"Server Monitor is a local-first monitoring solution that prioritizes your privacy. No data is ever transmitted to external servers."

Overview

Server Monitor ("the App") is an iOS application for monitoring servers and APIs. The App does not collect personal information or transmit any data to external servers. All data is stored exclusively on the user's device.

Information We Store

The App stores the following information only in the device's local storage:

  • Server names, URLs, and HTTP methods entered by the user
  • Authentication credentials (Bearer Token, API Key, etc.)
  • App settings such as check intervals and success conditions
  • Last server check results (status code, response time)

Network Requests

  • Server health checks: HTTP requests are sent only to URLs registered by the user.
  • Public IP lookup: When using IP restrictions, the App queries api.ipify.org for the current public IP address.

Push Notifications

Notifications are delivered via Apple Push Notification service (APNs) and contain only the server name and status. Permissions can be revoked at any time in device settings.
